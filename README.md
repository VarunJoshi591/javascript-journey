# JavaScript Journey 🚀

My 8-week JavaScript learning journey — from fundamentals to advanced JavaScript, Data Structures & Algorithms (DSA), and practical projects.

> **Goal:** Build strong JavaScript foundations, solve problems independently, and complete progressively challenging projects.
>
> **Study plan:** 8 weeks · approximately 3 hours/day · 56 days

## Learning Principles

- Learn one topic at a time in the prescribed order.
- For every topic: information → explanation → code example → practice → review.
- Do not move to the next topic until the current practice is reviewed and I am ready.
- Try problems independently. Ask for hints before requesting a full solution.
- Commit and push progress every day.
- Update this README as topics, quizzes, and projects are completed.

## Week 1 — Introduction to JavaScript

**Goal:** Understand JavaScript fundamentals, how it runs, variables, data types and type conversion.

- [ ] Day 1: Introduction to JavaScript — what it is, history, ECMAScript versions and how to run JS
- [ ] Day 2: Variables — `var`, `let`, `const`
- [ ] Day 3: Hoisting, naming rules and scopes
- [ ] Day 4: Data types — all primitive types and `typeof`
- [ ] Day 5: Type casting — conversion, coercion, implicit and explicit conversion
- [ ] Day 6: Practice and revision
- [ ] Day 7: Weekly quiz (10 questions) and revision

**Weekly deliverable:** JavaScript basics exercises.

## Week 2 — Expressions, Operators and Control Flow

**Goal:** Make decisions, evaluate expressions and repeat operations in JavaScript.

- [ ] Day 8: Arithmetic, assignment and comparison operators
- [ ] Day 9: Logical, unary, comma and conditional operators
- [ ] Day 10: Bitwise operators, BigInt and string operators
- [ ] Day 11: Equality — `==`, `===`, `Object.is()` and equality algorithms
- [ ] Day 12: Control flow — `if/else`, `switch`, `throw`, `try/catch/finally` and Error objects
- [ ] Day 13: Loops — `for`, `while`, `do...while`, `for...of`, `for...in`, `break` and `continue`
- [ ] Day 14: Revision, 10-question quiz and **Project 1 — Basic JavaScript program**

**Project 1 requirements:** Build a menu-driven calculator or number utility using operators, conditionals and loops. Include input validation, clear output, and a feature checklist in the project folder.

## Daily Git Workflow

Run these commands from the repository after checking your changes:

```bash
git status
git add .
git commit -m "feat: add [topic] examples"
git push origin main
```

Use descriptive commit messages, for example:

- `feat: add JavaScript introduction examples`
- `feat: add variable declarations practice`
- `feat: implement basic calculator project`
- `docs: update weekly learning progress`
